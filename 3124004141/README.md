# 论文查重程序（Java 版）

## 项目简介
基于余弦相似度算法实现的中文论文查重工具，采用命令行参数驱动运行，输入原文与待检测文本的文件路径，自动计算并输出文本相似度结果，适配课程作业自动评测标准。

## 环境要求
- JDK 8 及以上版本
- Maven 3.6 及以上版本

## 使用方法
### 直接运行（使用编译好的 jar）
命令格式：
java -jar main.jar [原文文件路径] [抄袭版论文路径] [输出答案文件路径]

## 功能说明
1. 中文文本预处理：自动过滤标点、数字、空格等无效字符
2. 中文分词：基于 Jieba 分词库实现精准分词
3. 相似度计算：采用余弦相似度算法计算文本重合度
4. 异常兼容：参数错误、文件不存在、编码异常均有处理，不会异常退出
5. 纯本地计算：无任何网络请求，仅读写命令行指定的文件

## 性能指标
- 千级字符文本运行耗时 < 1s，远低于 5 秒评测限制
- 运行峰值内存 < 100MB，远低于 2048MB 限制
- 无内存泄漏，程序运行结束资源自动释放
